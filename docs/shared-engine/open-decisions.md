# Open decisions

Resolve these before replacing either production engine:

1. Exact Python and QGIS versions supported and tested.
2. Pure Python geodesic implementation and numeric tolerances.
3. Meaning and validated value of each flight-time allowance.
4. Semi-auto capture behavior on turns, connectors, and recovery travel.
5. Route start-corner selection and deterministic tie-breaking.
6. Curved-turn geometry ownership: calculated route geometry or renderer hint.
7. Drone-profile release, compatibility, and correction policy.
8. Sync compatibility range between engine and contract versions.

Items two through seven determine reviewed fixture outputs.
